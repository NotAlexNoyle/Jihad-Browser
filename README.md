## About

Jihad Browser is the webOS 3 browser with the engine swapped out: the stock browser's interfaces
(Mojo, Enyo, or the newer Mochi design) on top of **Goanna**, the engine of the **UXP** platform
behind Pale Moon and Basilisk, in place of the 2011 WebKit. Same engine, same XPI add-ons, same
Personas, and the device's own Flash Player still working. It installs next to the stock browser
and touches nothing else.

| | |
|---|---|
| **Runs on** | webOS 3.0.5 and webOS CE 3.1.0, TouchPad and TouchPad Go |
| **Engine** | Goanna 6.9 (UXP), with its own NSS: TLS 1.2 and 1.3 |
| **Flash** | The Flash Player 10.3 already on the device |
| **Licence** | Apache-2.0 and MPL-2.0; bundled libraries under their own (`NOTICE`) |

## Features

### Real Flash games

<p align="center">
  <img src="docs/screenshots/flash-games.webp" alt="Flash games in play on the TouchPad, in the three interfaces" width="760">
</p>

The device's Flash Player 10.3 runs on today's pages, in its own process: animation, sound, touch
and keys. The first tap engages a movie, so drags and holds go to the game and not the page; a
double tap brings up the on-screen keyboard, arrow pad included, so keyboard games play with no
keyboard attached.

### Three interfaces, one engine

Mojo with its round buttons, the classic Enyo browser, or the newer Mochi design. Install one or
all three; each keeps its own profile, add-ons, Personas, history and bookmarks.

### Add-ons, Personas, Settings

<p align="center">
  <img src="docs/screenshots/addons-personas.webp" alt="Left: about:addons in Jihad Mojo, with Palefill installed. Right: about:personas in Jihad Mochi" width="760">
</p>

- **XPI add-ons** install from a web page and live in `about:addons`. Palefill comes installed.
- **Personas** skin the toolbar; `about:personas` is the gallery, and it searches Jihad's add-on
  site (addons.riverstonerelay.org) and addons.mozilla.org.
- **Settings** in Pale Moon's panes, more than 55 options, with `about:config` underneath.

### And

- **HTTPS that works**: the engine's own NSS and Mozilla's root list, not the device's 2009
  OpenSSL. TLS 1.3 on a stock 3.0.5 device.
- **Ads and trackers blocked** from EasyList and EasyPrivacy, built in, refreshed every four days.
- **Bot checks**: a site that turns Firefox 52 away is retried once as a current Firefox and
  remembered.
- **A memory guard**: a page that pushes the 1 GB tablet into swapping is stopped, with a notice
  and a link back, before the tablet stops answering.
- **GPU drawing** on the Adreno 220, WebGL 1, printing to IPP and AirPrint printers.

## Install

Install the `.ipk` for the interface you want with Preware or WebOS Quick Install (not
`palm-install`: it skips the install scripts).

| Interface | Package |
|---|---|
| Jihad Mojo (lightweight) | `net.riverstonerelay.jihad-browser-mojo` |
| Jihad Enyo (the classic browser) | `net.riverstonerelay.jihad-browser` |
| Jihad Mochi (newer design) | `net.riverstonerelay.jihad-browser-mochi` |

## Build

Any x86_64 Linux with git, podman, curl, binutils and xz; about 40 GB and several hours the first
time. Details in `docs/DEVICE-BUILD.md`.

```bash
git clone --recurse-submodules https://git.trueog.net/NotAlexNoyle/Jihad-Browser.git
cd Jihad-Browser
tools/host/build-novacom.sh          # novacom + novacomd into tools/host/bin/
sudo -b tools/host/bin/novacomd      # keep it running while a device is plugged in
build/webos-oe/build-all-device.sh   # packages land in build/webos-oe/out-ipk/
```

Developers start at `docs/PICKUP.md` and `docs/ENGINE.md`.

## Known issues

The short list; the rest, with causes, is in `docs/KNOWN-ISSUES.md` and `docs/MODERN-WEB.md`.

- Tested on a TouchPad running webOS CE 3.1.0 only; the TouchPad Go and stock 3.0.5 are untested.
- Heavy single-page applications (GitLab, Reddit's login) take tens of seconds of script.
- YouTube plays at 144p to 360p, decoded in software, and is heavy.
- Flash movies made for Flash Player 11 and later may show nothing (Run 3, Learn to Fly 3); the
  stock browser does the same. Flash Player itself is the device's and is not distributed.
- The TLS fix covers Jihad only, not the stock browser or Mail.
