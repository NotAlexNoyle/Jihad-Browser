# BrowserAdapter ↔ BrowserServer IPC contract (YAP)

This is the contract Jihad Browser must preserve **byte-for-byte**. The UI
(`app/`) and the BrowserAdapter NPAPI plugin already speak it; the Goanna
backend must reproduce it exactly so neither has to change.

Source of truth: `BrowserServerBase.h` (autogenerated from `YapCodeGen`) and
`BrowserPage.h` in the isis-project BrowserServer repo (cloned to
`../ref-BrowserServer`). Transport is **YAP** (YapServer/YapProxy/YapPacket,
from `libYap.a`) over a local socket, plus a **shared-memory framebuffer**.

> Do not edit `BrowserServerBase.h` by hand. If a command/message must change,
> change the `.yap` definition and regenerate. For the port we change **none**
> of it — only `BrowserPage`'s implementation.

## Framebuffer model

- On `connect`/`thaw` the adapter passes `sharedBufferKey1`, `sharedBufferKey2`,
  `sharedBufferSize` — two SysV shared-memory segments (double buffering) sized
  `pageWidth*pageHeight*4` (BGRA/ARGB32, see `BrowserOffscreenInfo.h` /
  `BrowserOffscreenQt`).
- BrowserServer renders the page into the inactive buffer, then sends
  `msgPainted(sharedBufferKey)` naming which segment is ready.
- The adapter blits that segment to the card surface and, when done, calls
  `returnBuffer(sharedBufferKey)` so the server can reuse it.
- `freeze`/`thaw` detach/reattach the buffers for backgrounded cards (memory
  reclaim). `setWindowSize` / `setVirtualWindowSize` resize the surface and the
  content viewport respectively.

The Goanna backend must render into these exact segments in the exact pixel
format and emit `msgPainted`/honor `returnBuffer` with the same semantics.

## Async commands (adapter → server)

Lifecycle / surface:
`connect(pageW,pageH,shmKey1,shmKey2,shmSize,identifier)`, `disconnect`,
`exit`, `setWindowSize(w,h)`, `setVirtualWindowSize(w,h)`,
`setScrollPosition(cx,cy,cw,ch)`, `setZoomAndScroll(zoom,cx,cy)`,
`scrollLayer(id,dx,dy)`, `freeze`, `thaw(shmKey1,shmKey2,shmSize)`,
`returnBuffer(shmKey)`, `pageFocused(bool)`.

Navigation / loading:
`openUrl(url)`, `setHtml(url,body)`, `forward`, `back`, `reload`, `stop`,
`clearHistory`, `getHistoryState(queryNum)`, `addUrlRedirect(re,type,redirect,userData)`,
`cancelDownload(url)`.

Input:
`clickAt(cx,cy,numClicks,counter)`, `holdAt(cx,cy)`, `keyDown(key,mods,chr)`,
`keyUp(key,mods,chr)`, `mouseEvent(type,cx,cy,detail)`,
`gestureEvent(type,cx,cy,scale,rotate,centerX,centerY)`,
`touchEvent(type,count,mods,touchesJson)`, `dragStart/dragProcess/dragEnd`,
`interrogateClicks(bool)`, `setMouseMode(mode)`, `setShowClickedLink(bool)`.

Find / selection / clipboard:
`findString(str,fwd)`, `clearSelection`, `enableSelection(x,y)`,
`disableSelection`, `selectAll`, `copy(queryNum)`, `cut`, `paste`,
`insertStringAtCursor(text)`, `isEditing(queryNum)`,
`getTextCaretBounds(queryNum)`.

Hit-testing / node info (all reply via a matching `msg…Response`):
`inspectUrlAtPoint`, `getInteractiveNodeRects`, `isInteractiveAtPoint`,
`isEditing`, `saveImageAtPoint`, `getImageInfoAtPoint`,
`getElementInfoAtPoint`, `hitTest`, `zoomSmartCalculateRequest`.

Settings:
`setUserAgent`, `setMinFontSize`, `setEnableJavaScript(bool)`,
`setBlockPopups(bool)`, `setAcceptCookies(bool)`, `clearCache`, `clearCookies`,
`setAppIdentifier`, `setNetworkInterface`, `setDNSServers`,
`disableEnhancedViewport(bool)`, `ignoreMetaTags(bool)`,
`setVirtualWindowSize`.

Popups / plugins / misc:
`popupMenuSelect(id,idx)`, `pluginSpotlightStart/End`, `hideSpellingWidget`,
`printFrame(...)`.

## Async messages (server → adapter)

Paint / geometry: `msgPainted(shmKey)`, `msgContentsSizeChanged(w,h)`,
`msgScrolledTo(x,y)`, `msgMetaViewportSet(...)`, `msgMakePointVisible(x,y)`,
`msgUpdateScrollableLayers(json)`.

Load lifecycle: `msgLoadStarted`, `msgLoadProgress(p)`, `msgLoadStopped`,
`msgLocationChanged(uri,canBack,canFwd)`, `msgTitleChanged(title)`,
`msgTitleAndUrlChanged(...)`, `msgUrlRedirected(...)`,
`msgDidFinishDocumentLoad`, `msgUpdateGlobalHistory(url,reload)`,
`msgFailedLoad(...)`, `msgSetMainDocumentError(...)`, `msgReportError(...)`.

Dialogs (each carries a `syncPipePath` for the reply): `msgDialogAlert`,
`msgDialogConfirm`, `msgDialogPrompt`, `msgDialogUserPassword`,
`msgDialogSSLConfirm(host,code,certFile)`.

Downloads: `msgDownloadStart`, `msgDownloadProgress`, `msgDownloadError`,
`msgDownloadFinished(url,mime,tmpPath)`.

Links / MIME: `msgLinkClicked`, `msgMimeHandoffUrl`, `msgMimeNotSupported`.

Editing / selection: `msgEditorFocused(focused,fieldType,fieldActions)`,
`msgIsEditing`, `msgRemoveSelectionReticle`, `msgCopiedToClipboard`,
`msgPastedFromClipboard`, `msgGetTextCaretBoundsResponse`, `msgCopySuccessResponse`,
`msgHighlightRects(json)`, `msgAddFlashRects/msgRemoveFlashRects`.

Page mgmt: `msgCreatePage(identifier)`, `msgPurgePage`, `msgClickRejected`.

Popups / plugins: `msgPopupMenuShow(id,menuDataFile)`, `msgPopupMenuHide(id)`,
`msgPluginFullscreenSpotlightCreate/Remove`,
`msgSpellingWidgetVisibleRectUpdate`, `msgShowPrintDialog`.

Query responses (matched to a request `queryNum`):
`msgInspectUrlAtPointResponse`, `msgGetHistoryStateResponse`,
`msgSaveImageAtPointResponse`, `msgGetImageInfoAtPointResponse`,
`msgIsInteractiveAtPointResponse`, `msgGetElementInfoAtPointResponse`,
`msgHitTestResponse`, `msgSmartZoomCalculateResponseSimple`.

## Luna service surface (separate from YAP)

`palm://com.palm.browserServer/clearCache`, `…/clearCookies` (used directly by
the UI). The daemon registers these via LunaService (`USE_LUNA_SERVICE`).

## Implication for the Goanna port

`render/browserserver/` keeps: the YAP server, the shared-buffer plumbing,
the daemon/LunaService registration, page-manager, SSL/cert glue.
`render/goanna/` replaces the body of `BrowserPage`: an `nsIWebBrowser` driven
into an offscreen widget, painting into the shared buffers and emitting the
messages above from Goanna listeners. See `../render/goanna/PORT-MAP.md`.
