1. **P1 — Search text leaks to other applications.** [jihadPageCommands.js:645](../../../render/goanna/components/jihadPageCommands.js:645) broadcasts the first 60 characters on every search. `JihadLunaService.cpp:505` accepts subscriptions from any app; line 553 also logs the payload. Searching confidential text therefore exposes it outside the browser. **Fix:** use opaque request identifiers, restrict result delivery to the owning card, and exclude query text from logging.

2. **P1 — One card consumes another card’s result.** [Browser.js:204](../../../app/source/Browser.js:204), [JihadBrowser.js:1559](../../../app-mochi/source/JihadBrowser.js:1559), and [main-assistant.js:374](../../../app-mojo/app/assistants/main-assistant.js:374) decrement outstanding requests before checking ownership or text. If A and B each await one result, A’s broadcast exhausts both counters; B’s result is discarded. Identical queries display A’s count in B. Comparing 60-character prefixes also accepts distinct long queries. **Fix:** correlate card, navigation generation, and request identity through the side channel; consume only matching replies, preserving YAP’s wire format.

3. **P1 — The 300 ms limit does not bound counting.** [jihadPageCommands.js:434](../../../render/goanna/components/jihadPageCommands.js:434) checks elapsed time only after a successful match. A match followed by a huge unmatched tail, or many unmatched frames, can monopolize the daemon well beyond 300 ms. Each synchronous `Find` itself is unbounded. **Fix:** search bounded chunks with deadline checks between them, yield execution, and cancel obsolete searches. Checking time only around whole-document calls is insufficient.

4. **P2 — Clearing the field permanently inflates outstanding requests.** [Browser.js:201](../../../app/source/Browser.js:201), Mochi’s `find:441`, and Mojo’s `findAsk:346` increment `_findOut` for empty strings. [BrowserPageGoanna.cpp:1470](../../../render/goanna/BrowserPageGoanna.cpp:1470) clears without replying. Every delete-to-empty leaves an unmatched request, surviving Done/navigation and allowing unrelated broadcasts to be consumed. **Fix:** either acknowledge clears consistently or exclude them from pending requests; invalidate pending state on close/navigation.

5. **P2 — Text-control matches lack an index and survive Done.** [jihadPageCommands.js:425](../../../render/goanna/components/jihadPageCommands.js:425) reads only `window.getSelection()`; [line 650](../../../render/goanna/components/jihadPageCommands.js:650) clears only that selection. Inputs/textareas have separate selection controllers. The supplied device logs already show `okapi` returning `index:0,total:1`: the bar cannot show “1 of 1,” and Done leaves the control’s match selected. **Fix:** obtain and clear the actual finder selection, including text-control selections in frames.

6. **P2 — Page JavaScript can change browser search semantics.** [BrowserPageGoanna.cpp:1471](../../../render/goanna/BrowserPageGoanna.cpp:1471) uses the existing [GoannaRenderPage.cpp:1444](../../../render/goanna/GoannaRenderPage.cpp:1444) finder without resetting case/whole-word options. UXP’s `window.find()` changes those options on the same docshell finder. A page calling it with case-sensitive or whole-word matching makes subsequent browser searches miss valid substrings, while the counter remains case-insensitive. **Fix:** explicitly set `MatchCase(false)` and `EntireWord(false)` for every browser search.

7. **P2 — Reopening strands Next; Enter searches twice.** [FindBar.js:46](../../../app/source/FindBar.js:46), [JihadFindBar.js:38](../../../app-mochi/source/JihadFindBar.js:38), and [main-assistant.js:308](../../../app-mojo/app/assistants/main-assistant.js:308) restore the visible word but clear the sent word and disable stepping. Next does nothing until editing. Enter invokes both the initial search and another forward search, skipping its first result. **Fix:** distinguish an offered query from an executed query; a first step should submit exactly one search.

8. **P2 — Escaping can overflow the notification limit.** [jihadPageCommands.js:645](../../../render/goanna/components/jihadPageCommands.js:645) limits characters before JSON serialization. Sixty U+0001 characters serialize into a 420-character payload; `DialogService.cpp:458` truncates it into invalid JSON. The card silently discards the result after consuming its counter. **Fix:** transmit a bounded opaque identifier instead of query text, or enforce limits on the complete serialized payload without truncating JSON.

9. **P2 — Ctrl can remain logically pressed.** [BrowserApp.js:367](../../../app/source/BrowserApp.js:367), Mochi `JihadBrowser.js:952`, and Mojo `main-assistant.js:471` retain `_ctrlHeld` across deactivation. Hold Ctrl, switch cards, release elsewhere, then return: ordinary F opens Find and prevents typing that character. **Fix:** clear modifier state on blur/deactivation and keyboard disconnect.

10. **P2 — Single-match wrapping is never announced.** [jihadPageCommands.js:642](../../../render/goanna/components/jihadPageCommands.js:642) requires `total > 1`. Next/Previous on a one-match page wraps silently, violating R3. **Fix:** recognize returning to the sole match as wrapping.
