1. **High — `dom/plugins/ipc/PluginInstanceChild.cpp`, `RecvJihadShowDone` / `Destroy`.** With two shows outstanding and `mJihadShowOwed` set, destruction can cancel tasks before the parent finishes processing those shows. A completion delivered after `Destroy()` then calls `AsyncShowPluginFrame()`, queuing a non-owning runnable on the destroyed instance. Actor deletion before its delayed deadline produces a use-after-free. **Fix:** clear owed state during destruction and reject scheduling/completions once `mDestroyed` is set.

2. **High — `dom/plugins/ipc/PluginInstanceParent.cpp`, `RecvJihadShow` / `RecvShow`.** If allocating or mapping the owned copy fails, `RecvShow` falls back to wrapping the shared surface, yet `RecvJihadShow` immediately acknowledges it as reusable. After another rotation, the child can repaint that memory while the image consumer still reads it; teardown can also invalidate its backing storage. **Fix:** acknowledge reuse only after making an owned copy or retiring every consumer of the borrowed surface.

3. **High — `render/goanna/BrowserPageGoanna.cpp`, `freeze`; `PluginInstanceParent.cpp`, `jihad_plugin_lane_set` / `RecvShow`.** Freeze returns through `maybePaint` before `pluginLaneFrame` can close the lane. It leaves both `gJihadLanesOpen` and process-wide `gJihadLaneOpen` set. A plugin subsequently created in another card has its invalidation suppressed despite having no working lane, and the fast-tick count remains elevated. Navigation and other paint-bypass paths similarly defer cleanup until a later paint. **Fix:** close synchronously at lifecycle transitions and bind suppression to the owning plugin instance.

4. **High — `render/goanna/BrowserPageGoanna.cpp`, `pluginLaneFrame`.** During the first 100 ms, a real page change reported through widget dirtiness or compositor requests is ignored. At `proofDue`, the code clears `pageDirty` and adopts the current compositor sequence without painting those changes. A one-shot change outside the plugin passes the overlap proof and can remain absent indefinitely. **Fix:** preserve those changes and require a normal frame before establishing the lane’s baseline.

5. **High — `layout/generic/nsPluginFrame.cpp`, `JihadLaneScan`.** An overlay transformed from local coordinates into the plugin’s rectangle can pass the proof: the scanner skips the transform item’s transformed bounds and compares its children’s local bounds against the plugin’s bounds. Filters can similarly paint beyond the scanned child bounds. `aEffect` only disqualifies a plugin inside an effect, not an effected overlay. **Fix:** compare conservative wrapper bounds in a common coordinate system, rejecting unsupported effects.

6. **High — `render/goanna/BrowserPageGoanna.cpp`, `pluginLaneFrame`; `layout/generic/nsPluginFrame.cpp`, `jihad_plugin_lane_proof`.** Open a separate-widget popup over the movie. The proof scans only the document’s display root, while the lane returns before the existing `CompositePopups` step. It can therefore overwrite the popup with movie pixels or omit a newly opened popup entirely. **Fix:** prohibit the lane while separate popup roots are active and close it when popup state changes.

7. **High — `render/goanna/BrowserPageGoanna.cpp`, `pluginLaneFrame` / `expressStep` / `pluginLaneClose`.** While the main thread releases the frame lock to pump the engine, the express producer can start and publish a compositor frame despite an open plugin lane. That compositor may still contain the old plugin image because invalidation is suppressed. The later `mPubSeq` check detects this only after publication; express publication also recreates GPU slot records that subsequent raw lane writes invalidate without recording. **Fix:** coordinate lane ownership under the frame lock, restore plugin invalidation before express production, and invalidate both producers’ cached frame records on handoff.

8. **Medium — `dom/plugins/ipc/PluginInstanceParent.cpp`, `RecvShow` / `JihadLaneCopy`.** `mJihadLastFrame` changes only when the copy succeeds. A null-surface clear, failed copy, or unsupported surface can leave the preceding opaque snapshot advertised as the newest frame while `gJihadPluginFrameSeq` advances. The lane then republishes an old movie frame after the real image changed or disappeared. **Fix:** invalidate the cached snapshot on every incoming frame and expose it only after a successful matching opaque copy.

9. **Medium — `render/goanna/BrowserPageGoanna.cpp`, `pluginLaneFrame`.** A layout shift can move the plugin between the 500 ms rectangle refreshes. The display-list proof flushes current layout but returns only a Boolean; the copy still uses the old `mEmittedFlashRects` coordinates. A same-sized plugin consequently gets painted at its former position until the rectangle cache catches up. **Fix:** obtain plugin identity and current bounds from the same proof operation used to authorize the copy.

10. **Medium — `layout/generic/nsPluginFrame.cpp`, `JihadLaneScan`.** Deflating text bounds by one quarter of their height can discard actual glyph ink, including accents or overlapping ascenders/descenders. Text whose surviving middle box misses the plugin is accepted even though its ink covers it, and the lane erases that ink. **Fix:** use conservative bounds or verified ink bounds without heuristic deflation.

11. **Medium — `render/goanna/GoannaRenderPage.cpp`, `CompositorAnimating` / `PluginLaneSet`.** Missing copy/proof exports disable the lane, but missing animation or suppression exports do not. An engine exposing copy/proof but lacking the animation query is treated as having no animations; lacking `lane_set` silently breaks damage attribution. **Fix:** require the complete capability set before opening a lane and fail closed when any required export is absent.

12. **Medium — `render/goanna/BrowserPageGoanna.cpp`, `pluginLaneFrame`.** When write-through `shmat` fails and the supported cached mapping fallback is used, the new lane writes pixels without the cache-clean step used by normal GPU publication. On ARM, the card can read stale movie pixels despite receiving fresh publication sequences. **Fix:** clean every newly copied destination range before publishing, including whole-frame seeding.

13. **Medium — `dom/plugins/ipc/PluginInstanceChild.cpp`, `AsyncShowPluginFrame` / `InvalidateRectDelayed` / `JihadPumpGlib`.** Draw deadlines and posted-draw state belong to multiple instances but use process globals. One instance’s send delays another’s draw; another instance’s delayed callback or destruction can clear `gJihadDrawPosted` while an immediate draw remains pending, allowing the shared pump to advance playback before that draw. **Fix:** keep draw timestamps per instance and represent shared pump blocking with accurately counted pending immediate draws.

14. **Medium — `render/goanna/BrowserPageGoanna.cpp`, `pluginLaneFrame` / `gpuJobStartNext`.** Set `mLane.drain` while waiting for GPU jobs, then remove the plugin or navigate before entry completes. The early “no plugin” return bypasses the reset of `drain`, leaving `gpuJobStartNext` disabled on subsequent ordinary pages. **Fix:** clear drain state before all eligibility returns and during lifecycle cleanup.
