1. **P1 — Clipboard temporary file permits arbitrary file corruption.** [EngineHost.cpp:686](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/render/goanna/EngineHost.cpp:686) opens predictable `/var/tmp/webkit-clipboard.jihad-<pid>` with `fopen("w")`, following symlinks. A local process can pre-create that name pointing at a file writable by the root-run daemon; copying then truncates it, writes clipboard contents and changes its permissions. Rename does not prevent this. **Fix:** create an unpredictable temporary file exclusively, retain its descriptor, use `fchmod`, and rename only that securely created file.

2. **P1 — ANGLE’s depth limit still permits a small shader to exhaust memory.** [MacroExpander.cpp:332](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/third_party/uxp/gfx/angle/src/compiler/preprocessor/MacroExpander.cpp:332) limits nesting but leaves expanded-token counts unbounded. With `#define D(x) x x`, roughly 26 nested `D(...)` calls materialize tens of millions of tokens through argument expansion and replacement insertion. This occurs inside synchronous native shader compilation, where the JS interrupt cannot rescue the daemon. **Fix:** enforce a shared expansion budget covering tokens, bytes and work before vector growth, across nested expanders.

3. **P1 — Revealed password fields enter plaintext form history.** [jihadLogins.js:131](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/render/goanna/components/jihadLogins.js:131) classifies fields solely by their current input type. A normal “Show password” toggle changes `password` to `text`; submitting then records the password in FormHistory’s unencrypted `value` column, including when Remember logins is disabled. **Fix:** exclude credential autocomplete tokens and fields previously identified as passwords, including revealed fields; do not classify credentials solely from their current type.

4. **P1 — Clearing one localStorage origin deletes other origins and service workers.** [data.js:349](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/packaging/prefsui/content/data.js:349) reduces the selected origin to a host and calls `browser:purge-domain-data`. UXP clears that host’s localStorage across ports, schemes and subdomains; its service-worker manager also consumes this notification. Clearing `http://example.com:8077` therefore affects `:8079`, HTTPS and subdomains. The acceptance test misses this because the second port’s IndexedDB row remains. **Fix:** clear localStorage using the exact principal; reserve domain purges for Forget.

5. **P1 — The guard can use a destroyed JSContext during shutdown.** [EngineHost.cpp:1691](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/render/goanna/EngineHost.cpp:1691) detaches an endless thread, while shutdown destroys XPCOM. [XPCJSContext.cpp:1263](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/third_party/uxp/js/xpconnect/src/XPCJSContext.cpp:1263) retrieves a context pointer that is never cleared or protected against destruction. A pressure-triggered call overlapping teardown can reach `JS_RequestInterruptCallback` with freed storage. Atomic pointer access does not protect the pointee. **Fix:** stop and join the guard before embedding teardown, and synchronize context publication and retirement.

6. **P1 — Script interruption and shedding are not associated with the same document.** [EngineHost.cpp:1615](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/render/goanna/EngineHost.cpp:1615) sets “thread critical” before knowing whether anything was interrupted. Shedding subsequently selects the newest navigation at [BrowserPageGoanna.cpp:2992](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/render/goanna/BrowserPageGoanna.cpp:2992). With older card A allocating heavily and newer card B displaying a small page, A’s script can be stopped but B discarded. If memory recovers, A remains broken without an explanation. An idle-triggered request can also interrupt unrelated content starting within the three-second window. **Fix:** acknowledge actual interruption with a document/navigation identity and shed that document; cancel stale requests.

7. **P1 — Login prompting can log passwords through the trace stack dump.** [DialogService.cpp:166](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/render/goanna/DialogService.cpp:166) invokes `DumpJSStack` for named-button prompts, including the new login prompt. 8. **P2 — Login confirmation goes to the last-created card.** [jihadLogins.js:192](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/render/goanna/components/jihadLogins.js:192) requests a windowless prompter. The singleton prompter dispatches through the sink last assigned by a page constructor, rather than the submitting document. Open A, then B, return to A and submit: B receives A’s confirmation, potentially remaining behind while A waits up to 60 seconds. **Fix:** resolve the submitting window to its owning card and carry that routing through the prompter.

9. **P2 — Forget silently retains locked saved logins.** [data.js:392](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/packaging/prefsui/content/data.js:392) skips login deletion when the master-password store is locked but still reports success. Because collection also omits locked logins, removing the site’s cookies can make it disappear from the list although its credentials remain. **Fix:** require unlocking before promising complete deletion, refresh the login inventory afterward, and report incomplete deletion explicitly.

10. **P2 — Forget cannot remove the site’s form history.** [data.js:389](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/packaging/prefsui/content/data.js:389) never removes FormHistory entries. The writer records only field name/value, without origin attribution, so exact domain deletion cannot be implemented from these records. The acceptance script actually expects the submitted note to remain after Forget, contradicting the broad “every kind of data” claim. **Fix:** maintain origin attribution and delete matching records without deleting another site’s history; otherwise narrow the advertised requirement.

11. **P2 — Updating a login can overwrite a different action-origin credential.** [jihadLogins.js:173](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/render/goanna/components/jihadLogins.js:173) searches all form-action origins and chooses the first matching username. Two forms on one page origin submitting to different authentication origins can legitimately have different passwords for the same username. Submitting the second overwrites the first record, including its action origin. **Fix:** match the action origin as well as page origin and username, using a deliberate policy for wildcard records.

12. **P2 — IPv6 origins are omitted or grouped under an incorrect host.** [data.js:45](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/packaging/prefsui/content/data.js:45) stops host parsing at the first colon. `http://[::1]` produces no host; `[2001:db8::1]` becomes `2001`. Their logins/storage therefore disappear or enter an incorrect group, and Forget misses them. LocalStorage reconstruction also omits required IPv6 brackets. **Fix:** parse origins through `nsIURI` and reconstruct authorities with correct IPv6 syntax.

13. **P2 — The test master password remains in a persistent preference.** [jihadLogins.js:93](/home/notalexnoyle/eclipse-workspace/Jihad/Jihad-Browser/render/goanna/components/jihadLogins.js:93) consumes `set:<password>` without clearing it. Normal preference persistence can therefore write the protecting password in plaintext to `prefs.js`; malformed commands are also logged verbatim. **Fix:** use an ephemeral test interface, or consume and clear the preference without logging its value.
