# render/browserserver — engine-agnostic render daemon + IPC

Derived from the isis-project **BrowserServer / BrowserAdapter / AdapterBase**
(Apache-2.0). This directory holds the parts of the render daemon that are
**independent of the rendering engine** and are kept unchanged across the
QtWebKit → Goanna swap.

> The upstream sources are cloned for reference at `../../../ref-BrowserServer`,
> `../../../ref-BrowserAdapter`, `../../../ref-AdapterBase`. During Phase 1 the
> reusable files are imported here (keeping their Apache-2.0 headers); the
> QtWebKit-specific files are replaced by the Goanna backend in `../goanna`.

## Keep (engine-agnostic)

- **YAP server / IPC**: `BrowserServerBase.{h,cpp}` (autogenerated interface —
  do not hand-edit), `IpcBuffer`, `BrowserSyncReplyPipe`, the YAP dispatch.
- **Daemon & lifecycle**: `Main.cpp`, `BrowserServer.{cpp,h}` (minus QtWebKit
  bits), `BrowserServerBase`, `BrowserPageManager`, `CpuAffinity`,
  `PluginDirWatcher`, `Settings`.
- **Shared framebuffer plumbing**: the shmem attach/return/double-buffer logic
  and `BrowserOffscreenInfo` pixel-format contract (the *interface*; the Qt
  implementation `BrowserOffscreenQt` is replaced).
- **LunaService surface**: `palm://com.palm.browserServer/{clearCache,clearCookies}`.
- **Backup manager, SSL/cert glue** (`BackupManager`, `SSLSupport`,
  `SSLValidationInfo`) — re-pointed at Goanna's cert APIs.
- **JSON utils** (`JsonUtils`, pbnjson usage).

## Replace (QtWebKit-specific)

- `BrowserPage.{cpp,h}` — `QGraphicsView`/`QGraphicsWebView`/`WebOSWebPage`
  internals → `render/goanna/BrowserPageGoanna` (`nsIWebBrowser` + offscreen
  widget). The **public method surface of `BrowserPage` is preserved** so the
  YAP command dispatch in `BrowserServerBase` calls it unchanged.
- `BrowserOffscreenQt.{cpp,h}` — Qt pixmap/QImage surface → a Goanna
  surface that paints into the same shmem buffer (`BrowserOffscreenInfo`).
- `WebKitEventListener.{cpp,h}` — QtWebKit signal handlers → Goanna
  `nsIWebProgressListener`/chrome listeners in the Goanna backend.
- Qt build deps (`qbsinterface`, `weboswebpage.h` from webkit-supplemental).

## Boundary

`BrowserServerBase` dispatches each YAP command to a `BrowserPage*`. We keep
that vtable identical and provide it from the Goanna backend. That single
boundary is what makes "swap the core, keep the IPC" mechanically possible.
