Flash test

Test movies for the Flash plugin in Jihad Browser. They live on the device's own storage (/media/internal/jihad-flash-test/), so this bookmark survives reboots.

Smoothness — a green square sweeping (30 fps) Frame rate — a square stepping through a grid (30 fps, 640×480) Keyboard — green until a key reaches Flash, then red

Games

Real Flash games, served as the original .swf files by the Internet Archive. They open full screen; tap the movie first. Keyboard games need a Bluetooth keyboard.

Helicopter Game — touch only (hold to fly) Bloxorz — arrow keys Motherload — arrow keys QWOP — Q, W, O, P keys Alien Hominid — keyboard

What to look for: the square should move at an even pace with no bunching or pauses; the keyboard test needs a hardware (Bluetooth) keyboard — tap the movie first to give it focus.
